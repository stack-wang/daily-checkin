# 每日打卡

一款 Android 打卡习惯追踪应用，支持自定义打卡项目、每日提醒、补卡和数据统计。

## 功能

- **打卡项目管理** — 新建、编辑、删除打卡项目，自定义图标、颜色和提醒时间
- **每日打卡** — 首页展示今日待打卡列表，一键打卡，误触可取消
- **精确提醒** — 每个项目独立设置提醒时间，到点准时推送通知
- **补卡** — 可补最近 N 天内的漏打卡（天数可配置），支持取消补卡
- **数据统计** — 打卡热力图、连续天数、打卡率、项目排行

## 提醒机制

采用 `AlarmManager.setAlarmClock()` 精确闹钟 + 前台 Service 保活方案：

- 每个打卡项目独立一个闹钟，到秒级触发
- 闹钟触发后自动检查今日是否已打卡，未打则弹出系统通知
- 通知触发后自动续订明天同一时间的闹钟
- 前台 Service 持持久通知告知系统「工作中」，降低后台被杀概率
- 开机自启重新调度所有闹钟

## 安装须知（重要）

### 首次打开 App 后会弹窗，请完成以下配置：

1. **闹钟权限**：点击「去设置」→ 找到「每日打卡」→ 打开开关
2. **电池限制**：长按 App 图标 → 应用信息 → 电池 → 设为「不限制」
3. **通知权限**：App 首次启动会自动请求

> 以上配置对国产手机（一加/华为/小米等）尤为重要，否则提醒可能被系统延迟或拦截。

## 技术栈

| 技术 | 用途 |
|------|------|
| Kotlin + Jetpack Compose | UI 框架 |
| Room | 本地数据库 |
| Hilt | 依赖注入 |
| AlarmManager | 精确闹钟提醒 |
| WorkManager | 每日闹钟同步备份 |
| Navigation Compose | 页面导航 |

## 构建

用 Android Studio 打开项目，Sync Gradle 后 Build → Build APK(s)。

或通过 GitHub Actions 自动构建：推送代码后，在 Actions 标签页下载 `app-debug.apk`。
